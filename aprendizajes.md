*¿Qué es Git y para qué sirve?*  
Git es un sistema de control de versiones que permite guardar cambios en proyectos. Sirve para trabajar en equipo y mantener un historial de modificaciones.

*5 comandos que más voy a usar*
- git add
- git commit
- git push
- git pull
- git checkout
